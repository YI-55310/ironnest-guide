How to Fix Missed Shots in Iron Nest

First shot lands short, long or wide? Here is the disciplined correction loop that walks your rounds onto the target.

The Correction Loop

Fire one observed round, classify the miss, adjust one matching variable, and fire again. Once target, shell, charges, elevation and bearing all come from the same written firing card, the workflow becomes far more consistent than solving each shot from memory.

Diagnose by Impact Direction

Observed ResultLikely CauseCheck FirstCorrection
Shot lands short Range too low, too few charges, or elevation too low Calculator range, charge count, elevation gauge Re-measure range from the current origin, then match charges and elevation to the calculator
Shot lands long Range too high, too many charges, or elevation too high Calculator input, loaded charges, elevation gauge Verify the measured distance and reduce only the value shown to be incorrect
Shot lands left or right Bearing wrong, or turret stopped slightly off heading Target line on the map, bearing on the firing card, rotation counter Recheck the target line, then use the fine traverse control to match the bearing precisely
Impact on target but objective fails Wrong shell type or incorrect mission target High Command order, target class, loaded ammunition Confirm the specified shell - AP for underground targets, HE for surface targets when the order supports it
Values look correct but round still misses Wrong origin, target point, gun or firing lane High Command message, current map origin, target coordinates, selected weapon Rebuild the firing card from the order before making a new adjustment

Use Spotter Feedback as a Controlled Loop

When a spotter report, aerial image or updated High Command message arrives, treat it as a correction to the current firing solution:

  • New target → fresh map measurements.
  • Lateral correction → bearing attention.
  • Consistent short or long pattern → range, elevation and charges.
The Golden Rule
Change one setting per shot. Altering range, bearing, elevation and charges all at once removes the feedback you need to see what worked.
